## 6. Уроки метода (для Главного-1, действуют с этого документа)

1. **Недоделанная проверка не приписывается инструменту.** «Не смог» пишется как «не сделал»; причина — только после того, как она установлена экспериментом.
2. **Хэш из скачанного base64 — только с перекрёстной проверкой.** Транскрипция длинного base64 даёт ~1 ошибку на 13 тыс. символов (установлено на T204). Порядок: записать base64 → декодировать → сверить длину с метаданными → сверить текст с `read_file_content` → посчитать хэш. Совпадение хэша — достаточное доказательство; несовпадение без второго канала — ничего не доказывает.
3. **Самоотчёт ≠ проверка.** Размер, хэш, число строк — только из независимого источника (метаданные Drive, собственный подсчёт, репозиторий).
4. **Листинг ПОЧТА — полный, с пагинацией**, без фильтра по дате; следующий номер письма — max+1 по полному списку.
5. **DATE письма — из `current_time` непосредственно перед загрузкой.**
6. **Имена метрик не должны предрешать интерпретацию.** `double_entities` и `key_conflicts` подтолкнули записку к выводу, которого данные не содержат; в заданиях называть числа по способу вычисления.
7. **Сводка владельцу — только то, что проверено.** Интерпретация подчинённого передаётся как его интерпретация, с указанием, что за ней стоит.
