## 9. Уроки цикла

- **«Завершено» без запуска и без рецензии — не завершено.** DDL, который ни разу не применили, не применялся вовсе.
  Handoff пишется только из фактов, полученных запуском в этой же сессии: коммит «в GitHub» — после `git ls-remote`.
- **Декоративное поле — дефект.** Поле, которое ни одно правило не читает (`version`, `is_abstract`, `symmetric`,
  `inverse_predicate_id`, `tenant_id` в литерале), либо получает правило с вектором и мутантом, либо удаляется.
- **По построению лучше, чем правилом.** Журнал как часть версии, формат идентификатора как данные, предикаты tenant в
  своём пространстве имён, производные таблицы только из триггеров — целые классы замечаний исчезли без правил.
- **Смена пометки версии у старых записей меняет их адреса.** Совместимое расширение не трогает ни одной прежней
  записи; это проверяется сравнением адресов мира с предыдущей версией.
- **Время.** Точность времени записи в наборе — секунда; база должна ставить время определений с той же точностью,
  иначе утверждение «в ту же секунду» расходится с ней.
