## 1. Что это и где граница

Ядро — общий язык данных шести продуктов. В v0.6 исполняемые части:

1. **Онтология 0.2.5** — схема, реестры, единственный нормативный валидатор, эталонный мир (94 записи), 358 векторов, 314 мутантов.
2. **Срез на PostgreSQL 16** — правила как ограничения и триггеры; каждое атакуется в обход валидатора; правила о времени — гонкой двух транзакций.
3. **Проекции** — досье, отчёт Проверки, провенанс, карточка оборудования и **лента упоминаний Web Monitoring (S5)**.
4. **Адаптер TechSense (S4).**
5. **Публикации Web Monitoring (S5, часть 1):** одна статья, полученная несколько раз с разными байтами (лишние пробелы и переводы строк, невидимые символы, мобильная и AMP-версии, метки перехода), — одна публикация и одна позиция ленты; поддержка факта считается по публикациям.

Пока нет: **объектного хранилища (S5, часть 2 — следующий цикл)**, идентификаторов СНГ (S6), досье в .docx, ролей пользователей в интерфейсах, реальных данных TechSense и Web Monitoring (папки `ВХОДНЫЕ_ДАННЫЕ/TechSense` и `ВХОДНЫЕ_ДАННЫЕ/Web_Monitoring` пусты).

## 2. Новые решения

| № | Решение |
|---|---|
| **D21** | **Публикация над источником.** Источник — байты одного забора; публикация — статья издания. Адрес публикации = sha256(JCS(tenant, издание, нормализованный текст)): одна и та же статья у разных загрузчиков получает один адрес. Нормализованный текст: невидимые символы сняты, NFC, каждый пробельный отрезок — один пробел, края без пробелов; регистр, буквы и пунктуация сохраняются (отредактированная статья — другой текст). Издание = хост канонического адреса без одного «www.», «m.» или «amp.»; канонический адрес — в нормальной форме (http/https, нижний регистр хоста, без порта по умолчанию, без фрагмента, без меток utm_*, fbclid, gclid, yclid, _openstat, mc_cid, mc_eid, параметры упорядочены, путь с «/»). **Рендеринги не перечисляются, а выводятся**: любой источник tenant с тем же текстом, полученный с этого издания; новый повторный забор присоединяется сам. Публикация опирается хотя бы на один рендеринг, полученный к её recorded_at; маркировка не шире рендерингов; дата выхода — не позже первого получения. Код `PUBLICATION_INVALID` (39-й). |
| **D22** | **Время и блокировки публикаций.** Текст источника становится известен базе при записи байтов (`source_texts.known_at`, после блокировки источника); публикация записывается после блокировок всех источников с её текстом (D14: тот же ключ `source:`, что берёт закрытие Проверки). Всё, что зависит от публикаций (рендеринги, ключ поддержки), считается на момент t по времени поступления — отчёт закрытой Проверки от поздних публикаций не меняется (D16). |
| **D23** | **Поддержка факта = различные публикации/источники.** Три забора одной статьи — одна поддержка (`ac.support_key`); повторный прогон службы — тоже одна (D19). |
| **D24** | **Лента не раскрывает чужие заборы.** Источники общие для tenant; в позиции ленты показываются только те рендеринги, на которые опираются видимые читателю утверждения его проекта; их маркировки входят в маркировку ленты; публикацию, которую читатель не видит, он не видит ни заголовком, ни адресом, ни идентификатором. |
| **D25** | **Версия Unicode закреплена (14.0.0).** Таблицы базы (ключи, невидимые символы, неназначенные кодовые точки) сгенерированы для неё; валидатор на другой версии отказывает (fail-closed), генераторы не запускаются. Текст с кодовой точкой, не назначенной в этой версии, или с NUL несравним (отпечаток отсутствует): нормализация назначенных символов стабильна между версиями Unicode, поэтому отпечаток не зависит от версии PostgreSQL. |

## 4. Проекция «лента упоминаний» (`slice/proj_s5.sql`)

`ac.wm_feed(project, entity, as_of, date_from, date_to)`: упоминания сущности (`wm.mentioned`, `media.negative_mention`) сгруппированы по публикациям — одна позиция на статью (издание, заголовок, канонический адрес, дата выхода, первое получение, версии-рендеринги, на которые опираются упоминания); одинаковые упоминания из разных версий — одно предложение с цитатами. Упоминание без публикации — отдельной позицией по источнику («публикация не заведена»). Правила доступа — как у досье (D15, D16) плюс D24. Рендер — `slice/render_s5.py`, образец — `slice/ПРИМЕР_ЛЕНТЫ_S5.md`.
