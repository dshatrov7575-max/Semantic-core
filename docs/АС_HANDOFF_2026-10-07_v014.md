## 7. Правила проверки, действующие с 06.10

Приняты по итогам аудита собственной работы (`АС_АУДИТ_2026-10-06_v001_T203-T204.md`, §6):

1. Недоделанная проверка не приписывается инструменту. Файл с Drive скачивается целиком через `download_file_content`; хэш считается по раскодированным байтам, длина сверяется с метаданными.
2. При переписывании base64 возможна ошибка в символе. Несовпадение хэша без второго канала ничего не доказывает; второй канал — текст из `read_file_content`.
3. Самоотчёт подчинённого — не проверка: размер, хэш и число строк берутся из независимого источника.
4. Почта проверяется поиском по `createdTime` позже последнего известного письма; номер нового письма — следующий за наибольшим.
5. Дата письма берётся инструментом времени перед отправкой.
6. Имена метрик не должны предрешать вывод: `double_entities` и `facts_no_quote` привели к неверным толкованиям.
7. Владельцу передаётся только проверенное; толкование подчинённого подаётся как его толкование.
8. Содержание проверяется по первоисточнику: строки набора и цитаты досье сверяются со страницами по их адресам.
