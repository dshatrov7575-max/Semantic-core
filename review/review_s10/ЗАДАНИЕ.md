Постоянные правила проекта, по которым судят работу:
1. «База выше заявления»: PostgreSQL сам отвергает всё, что отвергает валидатор (кроме заранее названных исключений),
   без валидатора перед ним.
2. «Новое правило — только с вектором и мутантом»: у каждого правила валидатора есть вектор, который его проверяет,
   и мутант, который без этого правила убивается; выживший мутант должен быть обоснованно эквивалентным.
3. Декоративное поле (которое ни одно правило не читает) — дефект.
4. Маркировки (уровень + категории) не обходятся: читатель без допуска не получает ни значения, ни факта существования.
5. Записи неизменяемы; производные таблицы пишутся только триггерами.
6. Самоотчётам не верить: число в отчёте проверяется запуском.
