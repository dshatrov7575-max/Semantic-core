## Отступления от проекта D27.2–D27.4 (названные)

1. Доказательство несёт путь включения (самодостаточно); пути через шлюз (`ac.dataset_row_checks`) и блокировки по ключу нет.
2. Соль ячейки = sha256(0x03 ‖ секрет строки ‖ имя колонки), не HMAC; секрет строки = HMAC(ключ набора, ключ строки).
3. Лист ячейки = sha256(0x00 ‖ соль ‖ JCS([имя, значение])): имя колонки входит в лист; префиксы 0x00/0x01/0x02 разделяют лист ячейки, узел и лист строки.
4. Маркировка источника-версии — маркировка манифеста (схемы), не максимум по колонкам; колонки маркируются отдельно, утверждение доминирует процитированные.
5. Корень Меркла — на файл (в манифесте), не один на версию; доказательство позиционное (файл, номер).
6. Доказательство несёт листья всех непроцитированных колонок (512 колонок — ≈46 тыс. знаков); сжатия (мульти-доказательства) нет.
7. Литерал утверждения сверяется с ОДНОЙ колонкой, объявленной для предиката (`predicate` колонки), а не «литерал = все процитированные колонки».
8. Файлы строк — JSON Lines, не колоночные; Iceberg-подмножество (удалённые ключи, дельты) — часть 2.
9. Широкие таблицы: секционирование по версии и b-tree; BRIN и RLS не делались; признака «индексируемый» нет — индекс идентификаторов строится у каждой запечатанной версии.
10. Субъект строки объявляется в манифесте (`subject`) — в проекте этого поля нет.
