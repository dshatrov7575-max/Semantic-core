# ЯДРО — онтология core-ontology/0.4 (исполняемая)

Нормативный текст — `АРХИТЕКТУРА_ЯДРА_v0.9.md` (цикл 10, часть 1: версия набора данных — источник с манифестом,
доказательство-строка `ROW`; проект решения D27.2/D27.4) и `АРХИТЕКТУРА_ЯДРА_v0.8.md` (цикл 9, D27.1 «Схема как
данные»). Здесь — код, который их проверяет.

| Файл | Что это |
|---|---|
| `core.schema.json` | JSON Schema 2020-12: набор данных (12 видов записей: прежние 9 + `ClassDef`, `LinkDef`, `IdentifierDef`), реестр доверия, артефакт `umr-artifact/0.3` (`$defs.UmrArtifact`) |
| `predicates.json` | реестр предикатов ядра (25, включая `schema.is_a`), профилей Проверки и ролей артефактов — данные, не код; предикаты tenant («x.…») живут в его схеме, не здесь |
| `dataset.py` | производитель версии набора данных: файлы строк, манифест, доказательство строки (нормативная арифметика — в `validator.py`) |
| `validator.py` | единственный нормативный валидатор (фазы 0–2, 47 кодов ошибок — из них 46 требуют вектор, `VALIDATOR_INTERNAL_ERROR` — предохранитель; 4 кода предупреждений, в цикле 11 добавлен `ROW_SUBJECT_CONFLICT`); схема tenant «на момент t», проверка утверждения по схеме своего времени |
| `jcs.py`, `jcs.mjs` | RFC 8785 JCS, UTF-8, целочисленный профиль (Python — норматив, Node — для производителей на JS) |
| `fixtures.py` | тестовый мир на все 6 продуктов + реестр доверия + хранилище байтов + артефакт TechSense + статья news.example в трёх версиях байтов + **версия набора данных** (демонстрационный реестр из 5 строк, утверждение на строке) + **схема tenant SemanticWiki** (классы «Таксон», «Вид китов» в двух версиях, «Музейный экспонат» с корнем `THING`, связь, тип идентификатора, утверждения `schema.is_a` и с предикатами tenant) |
| `vectors.py` | 681 вектор (539 негативных, 142 позитивных граничных) — из них 129 цикла 9 (N9xx/P9xx), 147 цикла 10 (NR../PR..) и 39 цикла 11 (NS../PS../WS.., N42A, P42A) |
| `tests.py` | приёмка T1–T9 (≈7 мин; T8 — закреплённая версия Unicode 14.0.0; T9 — Конструктор модели) |
| `mutants.py` | мутационный прогон: 535 мутантов, 10 эквивалентных (≈2,5 ч на 2 ядрах) — из них 98 цикла 9 (M900–M997), 90 цикла 10 (MR..) и 27 цикла 11 (MS..) |
| `model_constructor.py` | «Конструктор модели» — клиент реестра схемы из командной строки: каждая команда добавляет ОДНУ версию ОДНОГО определения, прогоняет весь набор через валидатор и пишет файл, только если ошибок нет (`python3 model_constructor.py --help`) |

Хранилище сырых оригиналов (сканы, PDF, страницы) — отдельный слой `../store/` (не часть ядра: ядро проверяет лишь то, что наблюдение *претендует* на оригинал с таким адресом и длиной; где физически лежат байты — дело слоя хранения, см. `АРХИТЕКТУРА_ЯДРА_v0.8.md`).

Адаптер TechSense — `../adapter/techsense_umr.py` (приёмка `../adapter/tests_adapter.py`).

Установка: `pip install jsonschema cryptography` (Python ≥ 3.11), Node ≥ 18 для T6.

```bash
python3 tests.py        # ALL PASS
python3 mutants.py      # killed + equivalent = всего, survived = 0
python3 validator.py world.json --trust trust.json --content-dir DIR   # DIR: файлы с именем = hex адреса (источники и артефакты)
```

Правило: новое правило добавляется только вместе с негативным вектором и мутантом, которого этот вектор убивает.
